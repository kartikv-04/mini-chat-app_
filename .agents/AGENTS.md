# Agent Rules and Guidelines for Threadr

Please see the root [AGENTS.md](../AGENTS.md) for the complete, canonical rules, architecture, directory structure, environment variables, and quality verification gates.

### Quick Verification Commands:
- **Backend Lint**: `npm --prefix backend run lint`
- **Frontend Lint**: `npm --prefix frontend run lint`
- **Backend Test**: `npm --prefix backend test`
- **Frontend Test**: `npm --prefix frontend test`
- **Frontend Build**: `npm --prefix frontend run build`
